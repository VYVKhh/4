# مؤسسة ملتقى العلم والثقافية 🎓

موقع ويب حديث وسهل الاستخدام لمؤسسة ملتقى العلم والثقافية.

## المميزات ✨

- **موقع احترافي** مع واجهة مستخدم عصرية
- **لوحة إدارة كاملة** للتحكم في محتوى الموقع
- **رفع صور وفيديوهات** بسهولة
- **روابط التواصل الاجتماعي** (فيسبوك، إنستغرام، تويتر، يوتيوب، تيك توك، تيليجرام)
- **حفظ دائم** للبيانات والصور على القرص
- **أمان عالي** مع تشفير كلمات المرور
- **بدون متطلبات خارجية** - يعمل على Node.js فقط

## المتطلبات

- **Node.js** (الإصدار 14 فما فوق)
- **Fly.io account** (للنشر على الإنترنت)

## البدء السريع

### 1️⃣ التثبيت المحلي

```bash
# انسخ ملفات المشروع
cd المسار/للمشروع

# شغّل الخادم
node 4.js
```

اذهب إلى: `http://localhost:3000`

### 2️⃣ الدخول لوحة الإدارة

- **الرابط**: `http://localhost:3000/admin`
- **اسم المستخدم الافتراضي**: `admin`
- **كلمة المرور الافتراضية**: `admin123`

**⚠️ غيّر كلمة المرور فوراً بعد الدخول الأول!**

### 3️⃣ النشر على Fly.io

```bash
# 1. ثبّت flyctl
# (اتّبع التعليمات من https://fly.io/docs/flyctl/install/)

# 2. سجّل الدخول
fly auth login

# 3. انشر المشروع
fly deploy
```

## ملفات المشروع

- **4.js** - الخادم الرئيسي (يحتوي كل شيء في ملف واحد)
- **Dockerfile** - لتغليف التطبيق
- **fly.toml** - إعدادات النشر على Fly.io

## الهيكل

```
مجلد المشروع/
├── 4.js                 # الخادم
├── Dockerfile          # إعدادات Docker
├── fly.toml           # إعدادات Fly.io
├── public/            # الموقع والواجهة الأمامية (ينتج تلقائياً)
└── data/              # البيانات والصور والجلسات (يتم حفظها تلقائياً)
    ├── data.json      # محتوى الموقع
    ├── users.json     # حسابات الإدارة
    ├── sessions.json  # جلسات تسجيل الدخول
    └── uploads/       # الصور والفيديوهات
```

## المميزات الرئيسية

### 1. لوحة الإدارة الكاملة
- تحرير محتوى الموقع
- رفع وإدارة الصور والفيديوهات
- تحديث روابط التواصل الاجتماعي
- إدارة حسابات المستخدمين

### 2. الأمان
- جلسات محفوظة بشكل دائم
- تشفير كلمات المرور
- حماية من الهجمات الشائعة

### 3. الأداء
- لا يحتاج npm install
- ملف واحد سهل التوزيع
- بيانات مخزنة محلياً (بدون قاعدة بيانات معقدة)

## النسخ الاحتياطية

للحفاظ على بيانات الموقع، قم بتنزيل مجلد `data` بشكل دوري:

```bash
fly ssh sftp get -a اسم-التطبيق /app/data ./نسخة-احتياطية-data
```
